# ADR-0002: Tenant resolution

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
None.

## Decision
The tenant comes from a claim in the signed-in session. All code reads ITenantContext. Subdomain per tenant is added later without code changes elsewhere.

## Alternatives considered
Subdomain first (needs a paid domain and wildcard). Path prefix. Tenant picker at login.

## Consequences
No cost now. A custom domain needs a separate approval.

## Design patterns used
Pattern: Ambient Context behind an interface.
