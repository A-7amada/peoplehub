# ADR-0009: OIDC versus current authentication

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Cookie auth with stored sessions, lockout, step-up and TOTP.

## Decision
Keep internal auth. Add optional per-tenant OIDC sign-in (for example Microsoft Entra ID) through the built-in ASP.NET Core handler, enabled by tenant settings. SSO is built when a customer asks.

## Alternatives considered
Managed identity provider (paid or hosted). Internal only (large customers will ask for SSO).

## Consequences
No cost for the app. Any paid identity provider needs approval.

## Design patterns used
Pattern: Adapter over identity providers.
