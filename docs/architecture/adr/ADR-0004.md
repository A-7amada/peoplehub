# ADR-0004: Platform tenant versus customer tenant

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
One SystemAdmin per company.

## Decision
A separate platform tenant manages tenants and subscriptions. Support access to customer data needs an explicit, time-limited, audited grant.

## Alternatives considered
SystemAdmin with global access (simple, unsafe).

## Consequences
Medium effort, no money.

## Design patterns used
Pattern: Separation of privilege.
