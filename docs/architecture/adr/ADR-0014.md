# ADR-0014: File storage

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Files live in the database (owner decision).

## Decision
An IFileStore interface with the database implementation as default. Per-tenant size limit and a warning near the free 1 GB storage limit. S3-compatible storage can replace it later.

## Alternatives considered
External object storage now (paid).

## Consequences
Small.

## Design patterns used
Pattern: Repository / Strategy.
