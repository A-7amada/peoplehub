# ADR-0017: Testing architecture

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
590 tests on SQLite. One Postgres smoke test skipped.

## Decision
Add architecture tests, tenant-isolation tests, and real Postgres tests in GitHub Actions with a service container. The same container is used for the restore drill.

## Alternatives considered
SQLite only.

## Consequences
Medium.

## Design patterns used
Pattern: Fitness functions.
