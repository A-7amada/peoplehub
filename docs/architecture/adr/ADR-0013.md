# ADR-0013: Cache

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
No distributed cache.

## Decision
An ICache interface with tenant-prefixed keys, backed by in-process memory. A Redis implementation is swapped in when several instances are needed (ARC-005, about 20 USD per month, deferred, needs approval).

## Alternatives considered
Redis now (paid, not needed on one instance).

## Consequences
Small. No cost.

## Design patterns used
Pattern: Strategy and Decorator.
