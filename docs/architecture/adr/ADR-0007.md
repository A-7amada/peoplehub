# ADR-0007: Country and policy separation

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Insurance, tax and leave rules live inside payroll services.

## Decision
Four layers: global HR rules, country rules (Egypt Pack first), company policy, employee override. Payroll executes calculation contracts and the country pack supplies the values with effective dates. Egypt values need sign-off by a labour lawyer and a payroll accountant before the first client.

## Alternatives considered
Keep rules in code per country (fast now, costly for KSA and UAE).

## Consequences
Large. Outside review needs separate approval.

## Design patterns used
Patterns: Strategy (calculation contracts), Policy / Specification, Effective-dated Configuration.
