# ADR-0019: Staging

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
One environment.

## Decision
A free staging service on Render plus a Neon branch (Free allows 10 branches). Migrations are tried there first. Deploy stays manual. The branch uses the shared 100 CU-hours.

## Alternatives considered
No staging. Paid staging.

## Consequences
Small, free.

## Design patterns used
Pattern: Environment parity.
