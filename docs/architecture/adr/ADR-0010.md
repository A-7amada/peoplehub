# ADR-0010: CQRS, selectively

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Plain services.

## Decision
Use explicit command and query handlers for Payroll and Reports only. No mediator library; handlers are called directly. Check any library licence before adopting.

## Alternatives considered
Mediator library. CQRS everywhere.

## Consequences
Medium.

## Design patterns used
Pattern: CQRS (selective), Command, Query Object.
