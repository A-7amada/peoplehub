# ADR-0018: Observability

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Health endpoints, in-process metrics, correlation ids, Diagnostics page.

## Decision
Structured logs with tenant and correlation ids and a metrics endpoint in OpenTelemetry format, no paid service.

## Alternatives considered
Paid APM.

## Consequences
Small to medium.

## Design patterns used
Pattern: Correlation id, Health Check.
