# ADR-0012: Background jobs: internal scheduler, not Hangfire

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Three BackgroundService workers, ScheduledJobState with lease and run records.

## Decision
Keep the internal scheduler. Add per-tenant execution, backoff retry and status in Diagnostics. Reassess Hangfire when moving to paid hosting or several instances. This keeps the earlier free-tier decision.

## Alternatives considered
Hangfire (extra database load on Neon Free, needs the host awake).

## Consequences
Small.

## Design patterns used
Pattern: Lease-based job runner, Template Method for job wrapper.
