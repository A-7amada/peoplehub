# ADR-0006: Data ownership per module

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
One shared context.

## Decision
Same database. Each table has one owning module that writes it. No separate schemas for now.

## Alternatives considered
Schema per module (clearer but complicates SQLite tests and migrations).

## Consequences
Small, done with ADR-0005.

## Design patterns used
Convention plus test.
