# ADR-0003: Tenant context in jobs, cache, files, settings

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Jobs run over all data. Settings are global. Files are in the database.

## Decision
One ITenantContext per request and per job scope. Background jobs iterate tenants and run each unit in its own tenant scope. Cache keys start with the tenant id. Settings are per tenant with platform defaults. Files carry TenantId.

## Alternatives considered
Pass a tenant id by hand into every method (error prone).

## Consequences
Medium effort. Isolation tests prove it.

## Design patterns used
Pattern: Scope per unit of work, Decorator for tenant-keyed cache.
