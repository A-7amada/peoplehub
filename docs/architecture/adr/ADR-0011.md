# ADR-0011: Domain events and outbox

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
Outbox exists for email and IntegrationEvent. No in-aggregate domain events.

## Decision
Aggregates raise in-memory domain events. On save they are turned into outbox rows in the same transaction. Other modules subscribe instead of calling each other.

## Alternatives considered
Direct calls between modules.

## Consequences
Medium.

## Design patterns used
Patterns: Domain Event, Transactional Outbox, Observer.
