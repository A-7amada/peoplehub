# ADR-0016: Security architecture

**Status:** Accepted (2026-11-25 22:50, Ahmed). Implementation status is tracked in BLUEPRINT.md.

## Context
RBAC, field grants, separation of duties, append-only audit, step-up, sessions. Field encryption deferred.

## Decision
Add tenant isolation to audit, permissions and support access. Write key management design in the Blueprint. Field encryption stays deferred because it needs key management.

## Alternatives considered
Encrypt now with an app-held key (weak).

## Consequences
Medium.

## Design patterns used
Pattern: Defence in depth.
